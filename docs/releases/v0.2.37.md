RatelMesh v0.2.37

This release brings the website and native clients onto the tested RatelMesh v3
brand system.

Highlights

- A simplified honey-badger mark preserves the product's distinctive identity
  while reducing the forehead mesh to three strong endpoints.
- The existing micro mark remains the 16–32 px tray, favicon and notification
  symbol after one-bit comparison testing showed it was clearer than the new
  alternatives.
- macOS, iOS and Android application artwork now comes from the same SVG master
  assets used by the website.
- Light, dark, monochrome and horizontal marks form one documented production
  asset set.
- The website social preview and all 13 localized download surfaces now point
  to v0.2.37.
- Brand generation and verification are reproducible on the Mac mini without
  GitHub Actions.

Artifact status

- macOS: Developer ID Application and Installer signed; Apple notarization is
  performed as part of the release gate.
- Windows: beta ZIPs for x64 and ARM64; not Authenticode signed.
- Linux: beta archives for x64 and ARM64.
- Android: debug-signed test APK; not a Play Store release.
- iOS: unsigned developer build; not directly installable and not a TestFlight
  release.

Install only from https://ratelmesh.com or https://download.ratelmesh.com.
Verify downloads with SHA256SUMS.txt.

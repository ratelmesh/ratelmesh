RatelMesh v0.2.41

This macOS release fixes DNS loss after sleep, wake, and network changes, and
hardens DIRECT and EXIT recovery.

Highlights

- RatelMesh waits for a usable physical DNS upstream before switching macOS to
  its protected local resolver, then retries after transient startup or wake
  failures.
- DNS forwarding supports TCP and automatically retries truncated UDP replies
  over TCP, including media domains used by YouTube and Google Video.
- DIRECT to EXIT to DIRECT transitions refresh DNS upstreams and preserve a
  recoverable fail-closed route instead of leaving the browser without DNS.
- Relay-to-direct probing, advertised endpoints, peer presence, and offline EXIT
  selection now have strict freshness and concurrency bounds.
- CHECK NOW receives the dual-signed v0.2.41 manifest from the official download
  host and verifies the package size and SHA-256 before opening Installer.

Artifact status

- The universal package is signed with the RatelMesh Developer ID Application
  and Installer identities.
- Apple notarization is not available for this build. Installation requires an
  explicit user confirmation; macOS may show a warning or require manual
  approval.
- The package is not installed silently and no Gatekeeper setting is changed.

Install only from https://ratelmesh.com or https://download.ratelmesh.com.
Verify the package with SHA256SUMS.txt.

RatelMesh v0.2.40

This macOS release fixes DNS recovery when the background service starts before
the default network route is ready.

Highlights

- macOS retries system DNS takeover after an early startup failure instead of
  leaving the menu connected to a local resolver that the system is not using.
- The daemon refreshes physical DNS upstreams when takeover succeeds, so
  switching between DIRECT and EXIT does not reuse an empty resolver set.
- Effective DNS status now reports whether system takeover actually succeeded.
- CHECK NOW receives the dual-signed v0.2.40 manifest from the official download
  host and verifies the package size and SHA-256 before opening Installer.

Artifact status

- The universal package is signed with the RatelMesh Developer ID Application
  and Installer identities.
- Apple notarization is not available for this build. Installation requires an
  explicit user confirmation; macOS may show a warning or require manual
  approval.
- The package is not installed silently and no Gatekeeper setting is changed.

Install only from https://ratelmesh.com or https://download.ratelmesh.com.
Verify the package with SHA256SUMS.txt.

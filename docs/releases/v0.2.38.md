RatelMesh v0.2.38

This release brings the Tenant Console, onboarding flow, native clients, and
command-line interface into one consistent 13-language experience.

Highlights

- The Tenant Console now defaults to English and supports English, Spanish,
  German, French, Japanese, Korean, Italian, Dutch, Polish, Swedish,
  Brazilian Portuguese, Simplified Chinese, and Traditional Chinese.
- First-device onboarding and recovery guidance are localized across all
  supported website languages.
- Android, macOS, iOS, and command-line user-facing strings now follow the
  same locale set as the website.
- Language switching preserves active console state without exposing secrets
  in translated URLs or browser history.
- Console routing aliases and language-prefixed query handling are more
  predictable.
- macOS update prompts and Android recovery messages are localized.
- Release checks now verify locale parity and generated native resources.

Artifact status

- macOS: Developer ID Application and Installer signed; Apple notarization is
  performed as part of the release gate.
- Windows: beta ZIPs for x64 and ARM64; not Authenticode signed.
- Linux: beta archives for x64 and ARM64.
- Android: debug-signed test APK; not a Play Store release.
- iOS: unsigned developer build; not directly installable and not a TestFlight
  release.

Install only from https://ratelmesh.com or https://download.ratelmesh.com.
Verify downloads with SHA256SUMS.txt.
